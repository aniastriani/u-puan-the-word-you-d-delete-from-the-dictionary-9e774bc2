The whole entry is a single word: **colonel**.

A colonel is spelled like a French pastry and pronounced like a
kernel of corn. Delete the word and the language loses nothing but
a spelling prank — the rank just becomes what it always sounded
like. A small deterministic Python program writes that exact word,
7 characters, no trailing newline, to `/output/entry.txt`. Run it
twice and the bytes are identical.

## Why this word

The joke is inside the word itself, not around it. Every reader
already knows the absurdity: five letters that promise "colo-nel"
and deliver "kernel". Deleting it is the only edit the dictionary
needs — the gap it leaves is filled by the sound the word was
already making. No explanation, no shock, just a spelling the
whole language has been politely pretending makes sense.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` is the packed entrypoint, compressed from the readable
`source.py` with `makefun compress`. Standard library only: no
dependencies, no network, no randomness.
